# Splash video review v3
Review only; app and earlier samples remain unchanged.
Two 8-second 720×1440 24fps H.264 loops use the v2 compositor and clean plate.
Cycle speed increased 1.5×; cloud travel 1.8×, boat translation 2×, water travel ~1.8×.
Star rays and reflection flecks are wider/brighter; moon glow increases gently.
No mesh warping. Large movements can reveal feathered layer boundaries, so compare at phone size.
Reproduce: node review/splash-film-v3/render.cjs
