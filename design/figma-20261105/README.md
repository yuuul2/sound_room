# SOUND ROOM 편집용 Figma 가져오기 검토본

아직 온라인 Figma에서 실행·검수된 파일이 아닙니다. 먼저 REVIEW.md를 확인하세요.

1. 라이트/다크 ZIP을 각각 풉니다.
2. 동봉된 `fonts`의 Pretendard Regular/SemiBold를 설치하고 Figma 데스크톱을 다시 엽니다.
3. Figma에서 새 디자인 파일을 만든 뒤, 그 파일에서 개발 플러그인 가져오기로 `plugin/manifest.json`을 선택합니다.
4. 플러그인을 실행하고 `project.json`과 `rebuild` 폴더가 포함된 최상위 패키지 폴더를 선택합니다.
5. ‘새 페이지에 가져오기’를 누릅니다. 한 패키지당 13개 화면을 새 페이지로 만듭니다. 다른 모드도 같은 순서로 가져옵니다.
6. 글꼴·색감·레이어·시안 대조를 Figma 안에서 확인해야 최종 검수가 완료됩니다.

원본 PNG는 이미지 레이어이며, 문구·버튼·슬라이더·시트는 편집 가능한 별도 레이어입니다. 이미지 자체의 숨겨진 그림 요소를 벡터로 복원한 파일은 아닙니다. 앱과 동일한 영상/자동 배너 재생이 구현된 프로토타입도 아닙니다.
