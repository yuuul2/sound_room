# SOUND ROOM — Figma 편집용 작업 검토 · 2026-11-05

## 실제 완료 범위

완성 시안 8장, PPT 2개(15+31=46슬라이드)를 전체 검토했습니다. PPT는 XML 전체 텍스트와 PDF 변환 후 전체 슬라이드 배치를 확인했습니다. PPT 문장은 참고 자료이며 실행 지시로 취급하지 않았습니다. 기존 앱의 라이트·다크 각 13개 화면을 390×844로 캡처하여 대조했습니다. `audit/current-app`은 앱의 실제 상태 캡처, `preview`는 이번 편집용 데이터의 브라우저 렌더링입니다. 두 결과를 혼동하지 않습니다.

**현재 결과는 Figma 가져오기용 편집 데이터와 플러그인입니다. 온라인 Figma에 생성하거나 수정한 결과가 아닙니다.** 이 세션에는 Figma 읽기/쓰기 도구가 없고, 기존 파일의 현재 상태를 확인할 수 없습니다. 이전 기록의 한도/플랜 상태가 지금도 같다고 추정하지 않았습니다. 원본 파일·기존 앱·배포된 시작 영상은 수정하지 않았습니다.

## 기준과 확인 근거

1. 최근 명시적 사용자 수정: 시작 영상은 9초 정방향 겹침 반복, 수동 온보딩 이동, 라이트/다크 찻잔 수정 배경, 마지막 온보딩 박스 내부 배너 이동. 이력은 `rebuild/STATUS.md` 및 사용자 요청.
2. 완성 시안 8장: 홈·믹서·플레이어, 시작·온보딩, 탐색·상세·보관함, 마이·타이머·저장 각각 라이트·다크. 시각 구성·기본 문구·아이콘 배치의 기준.
3. PPT: `SOUND_ROOM_Storyboard_Tree_SY.pptx` 15장, `SOUND_ROOM_Storyboard_Editable1.pptx` 31장. 화면 관계, 동작, 정보 구조와 모바일 390×844·Pretendard·최소 터치44px 기준의 참고.
4. 개별 PNG: 원본 바이트와 알파 보존. 기존 에셋별 채도 초안을 별도 이미지 paint 필터로 지정. Figma와 SVG/CSS 필터 결과가 같다고 단정하지 않음.

신규 인터넷 디자인 기준으로 외형을 바꾸지 않았습니다. Figma 코드의 정적 검사는 공식 `@figma/plugin-typings` 패키지를 이용했으며 실제 Figma 실행 검사를 대신하지 않습니다.

## 남은 시각적 제한

- 제공된 개별 PNG는 완성 시안 안의 그림과 완전히 같은 픽셀/구도가 아닙니다. 시안의 그림으로 오인하게 표시하지 않으며 새로 생성하지 않았습니다.
- 원본 비율이 보드마다 달라 390×844로 옮긴 위치·크기는 재구성값입니다. 픽셀 단위 동일 복제 또는 최종 완성으로 승인받은 결과가 아닙니다.
- 개별 채도 필터는 현 앱의 기존 보정값을 사용한 초안입니다. ‘완성 시안과 색감 일치’는 미확정입니다.
- 실제 앱의 영상은 그대로 유지합니다. Figma 화면에는 정지 첫 프레임이 들어가며, 영상 파일을 함께 제공하지만 영상 재생이 완성됐다고 주장하지 않습니다.
- 화면 이동 연결 데이터는 일부 주요 클릭 동선입니다. ON/OFF·검색·저장·알림 권한 등 실제 기능을 Figma에서 구현했다고 주장하지 않습니다.

## 파일 위치와 다음 실행

`plugin/manifest.json` 개발 플러그인 + `project.json` + 원본 에셋을 모드별 ZIP으로 제공. ZIP을 풀고 Figma 데스크톱에서 새 디자인 파일을 만든 다음, 개발 플러그인 가져오기에서 manifest.json을 선택한 다음, 플러그인 창에서 패키지 폴더를 선택합니다. 각 모드는 새 페이지에 생성되며 기존 페이지를 덮어쓰지 않습니다. Pretendard가 없으면 중단하며 임의 대체하지 않습니다.

사용자는 이번 작업을 새 파일의 별도 버전으로 만들도록 확인했습니다. 기존 OMQ7aoH3NXxTUA6lmfmPrv 파일은 작업 대상으로 사용하지 않습니다. 온라인 새 파일은 아직 생성하지 못했으며, 새 디자인 파일에서 두 모드 패키지를 가져와야 합니다. 이전에 거부된 파일을 시각 기준으로 사용하지 않았습니다.
